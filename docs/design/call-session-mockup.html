5. Why this is better than the current screen

  • The current screen closes the dialog and shows a six-second toast; there is then nothing to watch and nothing to press.
  • Call history is never refreshed, so a finished call can still read Presenting. The live bar and the 1 s refresh fix that.
  • Hang up is only inside the row's Actions menu. The bar makes it the primary action, and Cancel is distinct before anyone else is rung.
  • A call survives navigation; the current dialog and toast do not.
